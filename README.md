# 🚀 SpaceX — Java Game

A Java-based desktop game featuring multiple enemies, sound effects, boss battles, and score tracking.

## 🎮 About the Game

SpaceX is a desktop game developed in Java. The project combines interactive gameplay with enemy encounters, audio effects, and a leaderboard backed by SQLite.

## ✨ Features

- Multiple enemy types
- Boss battle featuring Shiva
- Sound effects for gameplay events
- Score tracking
- SQLite-powered leaderboard
- Java desktop interface

## 🛠️ Technologies Used

- **Java 21**
- **Java Swing** — graphical user interface
- **SQLite** — score and leaderboard storage
- **JDBC** — database connectivity

## 📁 Project Structure

- `src/` — Java source code
- `assets/` — game images and sound effects
- `lib/` — external libraries

## ▶️ How to Run

1. Install Java 21 or a compatible version.
2. Download or clone this repository.
3. Ensure the SQLite JDBC library is available in the project's library path.
4. Run the main class: `main.Main`.

**Note:** The exact launch steps may depend on your IDE and project configuration.
